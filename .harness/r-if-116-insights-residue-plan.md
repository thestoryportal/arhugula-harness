### Feature 5 — Red-first adversarial test-first harness (opt-in)

**U-WT-06 — `tools/mutation_probe.py`** (M–L) — highest-risk unit (writes source by design); land after U-WT-01 discipline is in force
- Interface: `uv run tools/mutation_probe.py --file F --lines A-B --test "<cmd>"`. Steps: (0) refuse if `git status --porcelain F` non-empty (exit 2); (1) run test, require PASS (probe against red test is meaningless → exit 2, distinct message); (2) read original bytes to memory, comment out lines A–B (`# ` prefix); (2b) **require the mutated file to remain syntax-valid (`ast.parse` for `.py`, `bash -n` for `.sh`) — a syntax-invalid mutation makes even a vacuous test fail at import/collection, faking probe success; reject the range with exit 2, distinct message** (codex round-5); (3) run test, require FAIL **with an identifiable test-level failure (e.g. pytest reporting ≥1 failed test / the named test id failing) — any other nonzero (collection, dependency, timeout) is indeterminate → exit 2, never probe-pass**; (4) restore in a `finally` from in-memory bytes — **but first verify the on-disk bytes are still exactly what the probe wrote; on mismatch (a concurrent writer touched F mid-probe) REFUSE to restore and fail loudly, since blind restore would silently clobber the concurrent edit and `git diff --quiet` would still pass** (merge-gate lens-1) — then verify `git diff --quiet F`, hard-error loudly if restore failed; also write an on-disk backup sidecar (`F.mutprobe.<pid>.bak`) before mutating; startup reconcile restores ONLY sidecars whose embedded pid is dead (`kill -0` fails) — an unconditional reconcile would restore a CONCURRENT live probe's file mid-run (merge-gate R2) — so a SIGKILL'd probe's original is recovered on the next invocation rather than leaving commented-out source; **the sidecar is REMOVED atomically after the verified restore (retained only on crash/mismatch) — a surviving success-path sidecar would be restored by a later dead-pid reconcile over valid edits made since (codex delta-pass, P1)**; (5) exit 0 probe-pass / exit 1 `PROBE FAILED: test stayed green with F:A-B removed`. **No `git stash`, no `git checkout --` anywhere.**
- AC: (1) real test + load-bearing lines → pass; (2) vacuous test → fail with named message; (3) dirty file → refuse, file untouched; (4) CHILD test killed mid-run → file byte-identical immediately (the runner's `finally` restores — fixture kills the child, not the runner); runner itself SIGTERM'd → an installed SIGTERM handler raises so `finally` unwinds; runner SIGKILL'd (no in-process recovery possible) → next invocation restores from the sidecar and says so — the immediate guarantee explicitly excludes SIGKILL (codex); (5) already-red test → exit 2 distinct, not false pass; (6) range whose removal breaks syntax (e.g. sole statement of a suite) → exit 2 rejected-range, NOT probe-pass, and a vacuous test paired with such a range must not be reported as killed. **As-built (PR #1206, 7 codex rounds + gate): the gate added a TARGET-SCOPED `F.mutprobe.lock` (flock on the open description — kernel-dropped on death, file permanent-by-design, never unlinked; simultaneous same-target probes were reproduced 5-in-6 wrong pre-fix) and a step-3-end interference re-verify (on-disk bytes must still be THIS probe's mutation, else INDETERMINATE); exit contract gains a documented 3 (RESTORE FAILED / RESTORE REFUSED / SIDECAR NOT RELEASED — fail-closed family; the file may be mutated, or restored with the crash-recovery sidecar retained); syntax gate is `compile(..., 'exec')` not `ast.parse` (compile-stage errors like orphaned `nonlocal` faked kills) and covers `.yaml`/`.yml`; step 0 additionally refuses untracked/gitignored/skip-worktree/assume-unchanged targets (both git witnesses are index comparisons that pass vacuously there) and step 1b refuses a baseline that itself writes the target (snapshot is read AFTER the baseline — a generator/autofixer edit is never silently discarded); pytest kills require rc==1 with the `py.test` alias recognized (err-toward-matching rule: the pytest branch is stricter); group-kill signals the known pgid with every wait bounded (a setsid-escaping grandchild reproduced a real pre-fix hang); sidecar header v3 carries THREE witnesses — integrity (original sha256+len), applicability (mutation sha256+len), git identity (index blob oid) — so the reconcile can never replay across post-crash edits or branch switches; all publishes are atomic-or-absent (`.tmp`/`.new` staging inside the `.mutprobe.` grammar, mode-stamped — os.replace strips the exec bit otherwise; verified direct-write fallback ONLY for restore/reconcile in write-denied dirs, announced, residual stated); all staging 0600 regardless of umask. REGISTERED RESIDUAL (stopping-rule applied at round 7): xattrs/ACLs/ownership are NOT preserved across the inode swap and git cannot witness the loss — stated in docstring + --help; refusing xattr-bearing targets would over-refuse on macOS quarantine attrs.
