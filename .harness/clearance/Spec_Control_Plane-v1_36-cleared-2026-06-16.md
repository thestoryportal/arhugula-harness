# Clearance — `Spec_Control_Plane v1.36`

v1.36 is the **R-spec-1 (L3) leg** of the R-FS-1 **R** sub-program (routing intelligence) — a single additive sub-section **C-CP-02 NEW §2.5** committing the **Layer-3 LLM_AS_ROUTER resolution surface**: the injected, **optional** async `RouterResolutionFn` that resolves the `llm_as_router` layer at the already-async `infer()` call surface when the deterministic layers fall through (`route()` returns the `candidate=""` / `layer="llm_as_router"` sentinel). It materializes the §2.1-named-but-unbound Layer 3 across the sync-`route()` / async-`infer()` decomposition that R-300 (2026-06-01) introduced.

**Reading B (probe-resolved, NOT council-convened).** The Layer-3 router call resolves at `infer()` — the "probabilistic core" per ADD §5.3.3. **Reading A** (widen `route()` + `LayerDecisionFn` async to host the router call inside `route()`) is **foreclosed**: a probabilistic model call (§2.2 "One full LLM call; 50–200 ms"; "Probabilistic") cannot sit in the sync layer §5.3.3 designates the deterministic outer harness, and it carries the largest blast radius (every `route()` caller + the cleared U-CP-05 contract). The 2026-06-11 confirm-defer (`class_2_fork_llm_as_router_layer3_contract_shape_vs_defer.md`) named a C1⊥C11⊥C9 tension; each leg is now foreclosed by a committed constraint (build-vs-defer by the standing FULL-SPEC directive; determinism by §5.3.3) → no design-time operator gate survives → probe-resolution, not convening (CLAUDE.md §10.9).

**Additive, not breaking — the router callable is OPTIONAL.** Absent an injected router (DECLARATIVE-only deployments + the entire pre-R-impl-1-binding state), and when the L3 budget is exhausted (L3 is terminal), `infer()`'s existing `RoutingCandidateUnresolvedError` raise (`routing_core_surface.py:177-182`) is **PRESERVED VERBATIM**. Every existing `infer()` caller is byte-for-byte unbroken. The rebuilt Layer-3 trace uses only the four frozen `RoutingDecisionTrace` fields; the router **rationale** rides the C-CP-01 §1.4 `routing.binding_rationale` optional span attribute (`:261`) — the frozen `extra="forbid"` 4-field trace is **NOT widened**. **No-regress invariant:** the router callable dispatches DIRECT against a pre-bound model and MUST NOT re-enter `route()`/`infer()` (infinite-regress hazard).

**Discharges the R-DESIGN §7(a) fork-to-file.** R-DESIGN §7 named, as a Class-1 fork to file at R-spec-1 authoring, "(a) the C-CP-02 §2.1 re-decomposition shape (router resolves at `infer()`) — the contract-section vs new-sub-section choice." The discharge is recorded greppably here + in the v1.36 change-note. **No separate `class_1_fork_*.md` is owed** — the genuine Reading-B-vs-A fork was already decided + cleared at #596; this leg applies it.
