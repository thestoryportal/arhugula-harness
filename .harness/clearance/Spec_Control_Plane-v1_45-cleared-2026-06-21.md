# Clearance — `Spec_Control_Plane v1.45`

v1.45 is an additive delta over v1.44 absorbing the **R-FS-1 standalone arc `B-HIERARCHICAL-PAUSE`**. It adds one C-CP-26 §26.2 carrier (`PausedChildBranchResumeState` — a worker branch whose recursive child sub-workflow returned PAUSED, carrying the child's nested `PauseSnapshot`), one additive `FanOutResumeState.paused_child_branches` field, and one additive hash-inert `StepExecutionContext.child_resume_snapshot` field, materializing the cleared **§25.15.1 `pause → PAUSED`** row + the **§25.18 impl-discretion recursion cascade** for the HIERARCHICAL_DELEGATION topology.

**Two halves, one arc.** (a) **Level-local** — HIERARCHICAL now threads `pause_resumable=True` + the resume snapshot (it reuses `_execute_orchestrator_workers` at each level), so a worker pause at a level materializes via the v1.42 `FanOutResumeState` mechanism. (b) **Cross-recursion-boundary** — a `SUB_AGENT_DISPATCH` worker whose recursive child PAUSED (a grandchild failing under `cascade_policy=pause`) was previously SWALLOWED as success-equivalent at the runtime dispatch boundary (silently dropping the child's suspended state). The dispatcher now raises the typed `SubAgentChildPausedError`; the parent captures the child's cursor into `paused_child_branches` + PAUSES; `api.resume` re-enters the child at its cursor via the threaded `child_resume_snapshot`.

**The third branch disposition (the load-bearing correctness).** A paused-child branch is re-dispatched THROUGH the child's own resume — NOT skip-terminal, NOT re-dispatch-fresh. Re-dispatching it fresh would silently re-execute (lose) the grandchild's already-completed work; the discriminating witness asserts a grandchild completed-before-pause is dispatched exactly once across the pause + resume (`[[full-chain-witness-not-half-proofs]]`).

**NO operator gate.** §25.15.1 already commits `pause → PAUSED` byte-exact; **§25.18 explicitly names "`cascade_policy` default propagation at `HIERARCHICAL_DELEGATION` recursion" under "Deferred to implementation discretion (NOT design holes)"** — this arc IS that materialization. Additive carrier + fields + opt-in (PAUSED only with a bound protocol; a child PAUSE under proceed/cascade-cancel FAILS honestly via `orchestrator-workers-child-paused-not-resumable-under-proceed` / the cascade-cancel FAILED — never a silent success); `snapshot_hash` extended (covers `paused_child_branches` transitively when non-empty, DROPPED when empty so every pre-arc ORCHESTRATOR_WORKERS / PARALLELIZATION snapshot is byte-identical); no new ADR / enum / CXA edge / manifest field.

**Carrier shape resolved in-impl (NOT operator).** The paused-child info is a NEW field on `FanOutResumeState` (since HIERARCHICAL IS ORCHESTRATOR_WORKERS at each level, the paused-child belongs inside that fan-out's resume state), NOT a top-level `PauseSnapshot` sibling (the v1.44 `peer_fan_out_resume` mutually-exclusive shape). The additive default-empty + drop-when-empty hashing preserves the v1.44 byte-compat discipline. A reversible in-impl design choice.

Reviewed during clearance: the carrier self-nests (a child snapshot may carry its own `paused_child_branches` — recursive Pydantic resolved via one `FanOutResumeState.model_rebuild()`); the hash covers the nested grandchild cursor (a tampered child snapshot fails the parent resume recompute, verified by execution) AND preserves byte-compat for pre-arc snapshots (drop-when-empty, verified by execution); the resume material-diff guard validates each paused-child branch's bounds + identity + no-overlap-with-terminal-`branches` (the two dispositions are disjoint); the typed `SubAgentChildPausedError` lives in harness-cp (runtime depends on cp → CP catches it typed without importing a runtime exception, axis isolation); the discriminating full-chain witness drives real recursive `execute_workflow → child fan-out pause → parent capture → api.resume → child re-entry at cursor` and asserts the grandchild ran exactly once (CP `test_workflow_driver_parallelization_pause.py`… in `test_workflow_driver_fanout_pause.py`), with the runtime dispatcher raise + resume-forwarding unit-proven in `test_lifecycle_sub_agent_dispatch.py`. NB: the INFERENCE-child real-provider e2e is blocked by a pre-existing runtime sync/async deadlock (`.harness/runtime_defect_sub_agent_inference_child_loop_bridge_deadlock.md`), so the witness is declarative-only by necessity, NOT an under-proof of this arc.
