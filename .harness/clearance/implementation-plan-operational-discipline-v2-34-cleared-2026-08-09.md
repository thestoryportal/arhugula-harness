# Clearance — `Implementation_Plan_Operational_Discipline_v2_34.md v2.34`

v2.34 is the OD plan leg of the **`B-123`** repair, filed in the same PR as its sibling spec leg (`Spec_Operational_Discipline_v1_39.md`) and the implementation, per the `B-116-t3` / `B-133` bundled-leg precedent. It carries **ONE new unit, U-OD-60**, and **amends none**.

**What U-OD-60 is.** Roughly four functional `src` lines: a derived §10.2 event-name constant composed from the two existing name constants (never re-literalled, so a rename reaches the span arm and the event arm together) plus an event-scan arm appended to `is_classification_trigger` after the existing name and attribute checks, so a name-matching span never pays for the scan. Everything else in the unit is the witness set and the docstring record. `tail_keep_span_processor.py` receives a **minimal** logic change, scoped to the single-read discipline: `on_end` reads `span.events` ONCE and threads that snapshot into both helpers, each gaining an optional `events` parameter defaulting to `None` so every existing caller stays byte-identical. Its control flow, arms and ordering are unchanged. *(Filed as comment-only; corrected after out-of-family Codex round 1 raised a [P2] showing the widened predicate re-read `span.events` per ordinary buffered span — a regression this arc introduced. Taken, and witnessed by AC11's `== 1` counting double.)*

**Why the witness set is shaped the way it is.** The behavioural core is AC #4, a REAL charging-fault dispatch driving a REAL breaker trip with a buffered *sibling* span — not merely the trip's own carrier — proven to export **without `force_flush`**, since a flush would mask the very mechanism under test. The trace arrangement is asserted rather than assumed (`carrier.parent is not None`), so the witness cannot pass by accident through the carrier being its own root. AC #5 is the discriminator that keeps the two rosters apart: `fallback.exhausted` is a §9.2 member but not a §10.2 trigger, so collapsing the two-member §10.2 set into the nineteen-member §9.2 SSOT makes it a false-positive trigger and fails there. AC #7 proves the cheapest-first short-circuit structurally — a span double whose `.events` property raises if touched — rather than by timing.

**Three things this leg recorded rather than smoothed over.** (i) A count claim in the draft ("two production call sites") was recounted programmatically and is **three**; corrected in both places, with the unaffected substantive disposition stated as unaffected. (ii) The PD-8 table asserts correspondence, not measurement, because the implementation was landing concurrently — and it says so in a preamble rather than quietly presenting predictions as results. (iii) A Class-3 rider the register queued for this delta was **falsified** by direct read and dropped, independently at both legs.

What was reviewed during clearance: the unit's dependency derivation (U-OD-11 as the module owner via the v2.26 canonical-reading amendment; U-OD-59 as the pattern and witness owner); the cross-axis disposition re-derived by grep rather than inherited; the axis-isolation constraint on the new OD-local witness file verified by import inspection; the not-edited surfaces asserted by absence. Deferrals: none — the derived constant's name and home and the scan's early exit are the implementation discretion `Spec_Operational_Discipline_v1_39.md` §1.3 delegated to this unit, and they are resolved here.

Note for Phase 7 consumers: U-OD-60 is **admission-bounded** and must not be read as delivering a full §10.2 floor. It changes what happens to the sibling tree for carriers that reach the tail; it does not change how many reach it. §10.2 row 1 is outside this unit entirely.
