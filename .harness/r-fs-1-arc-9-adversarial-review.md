## Post-review addendum — out-of-family Codex decorrelation (filed with the final commit `a9f7f3a`)

This adversarial review (above, against commit `d9ad7de`) found the impl **CORRECT** on every correctness axis it attacked (regression, determinism, scope, X-AL-3, nested-uniqueness) and surfaced only doc-hygiene. **Decorrelation value:** the out-of-family Codex reviewer (`just codex-review`), run on the same diff, then caught **three genuine [P2] correctness issues this agent + the advisor both missed** — all fixed to Codex convergence (clean) before merge:

1. **`bounded_barrier` leaked sibling tasks on a branch exception.** Bare `asyncio.gather` propagated the first branch exception without cancelling/awaiting still-pending siblings → orphaned branches could keep dispatching effects past the barrier (the §25.15.2 obl. 8 foreclosed `gather`-leak). Fix: leak-free `finally` that cancels + awaits pending tasks on any non-clean exit — policy-neutral (re-raises unchanged; `gather` kept, not `TaskGroup`, to preserve the §25.11 no-cascade form + not foreclose `proceed`). Regression test added.
2. **The determinism-test branch helper composed duplicate same-branch idempotency keys.** `_run_branch` reused the inherited (constant) spawning `step_index` for every branch step → a real dedup-ing IS writer would silently drop all but the first step per branch. Fix: use the branch-local step ordinal; added a same-branch-key-distinctness test.
3. **A branch-local `TimeoutError` was misclassified as the barrier deadline.** `except TimeoutError` caught both the `asyncio.timeout` deadline AND a `TimeoutError` raised *inside* a branch (e.g. a provider client timeout), wrongly converting the latter to `BranchBarrierDeadlineExceededError`. Fix: disambiguate via the `asyncio.timeout` context's `.expired()` and re-raise a branch-local timeout unchanged. Regression test added.

Advisor pre-done additionally caught: the new public symbols were missing from `workflow_driver.py.__all__` (added); the `BufferingLedgerWriter` docstring overclaimed the writer-swap was sufficient (sharpened to "necessary but not sufficient — the strategy must also compose branch-unique action_ids"); the linear inline-append regression was verified present at `test_workflow_driver.py::test_state_ledger_append_per_step` (cited, then grep-confirmed).

Net: this agent's review held on correctness-of-what-it-attacked, but the **3 P2s Codex found are the decorrelation case study** (`[[hooks-codex-pilots-decorrelation-validated]]`) — an out-of-family reviewer on the artifact catches the concurrency/dedup edge cases a transcript-aware reviewer and a spec-faithful adversarial agent structurally under-weight.
